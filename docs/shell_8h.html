typedef void(shell::* cmd_handler) (int argc, char **argv)

Function pointer type for command handlers (cmd_* functions).

Command handlers execute the main command functionality and are responsible for invoking any associated flag handlers (f_* functions) if any flags were supplied via terminal input.

Parameters
argcNumber of parsed arguments (command + flags + parameters)
argvArray of pointers to parsed argument strings

◆ command_id_t

enum command_id_t

Enumerated list of system commands.

Each command string parsed from user input is converted into one of these IDs. The mapping is performed by comparing user input against the command lookup table (shell::cmd[]).

Note
The order of this enum must match the order of the entries in shell::cmd[] to ensure correct indexing
