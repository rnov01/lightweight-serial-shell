◆ cmd_handler

typedef void(shell::* cmd_handler) (const command_rt_t *self, int argc, char **argv)

Function pointer type for command handlers (cmd_* functions).

Command handlers execute the main command functionality and are responsible for invoking any associated flag handlers (f_* functions) if any flags were supplied via terminal input.

Parameters
argcNumber of parsed arguments (command + flags + parameters)
argvArray of pointers to parsed argument strings

typedef void(shell::* flag_handler) (const command_rt_t *parent, int argc, char **argv)

Function pointer type for flag handlers (f_* functions)

These functions implement the behavior of flags/subcommands associated with a primary command. They are called only from within their respective cmd_* command handler.

Parameters
argcNumber of parsed arguments
argvArray of pointers to parsed argument strings
