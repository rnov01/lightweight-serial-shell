Detailed Description

Driver class for the serial shell interface.

The shell provides a minimal cli over a serial communication link (typically USART). It supports:
- command parsing
-argument tokenization
-flag-based subcommmands
-automatic help generation

The shell is designed to be lightweight, non-blocking, and easily adapted to different communication drivers.
